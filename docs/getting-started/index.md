# Getting started

Trim is a Mac app for Apple silicon, macOS 15 or later. It needs Neovim 0.12 or later, which the installer
takes care of.

1. [Install it](installation.md).
2. [Open a folder and look around](first-steps.md).

Everything else is optional, and you can read about it when you reach for it.
