# Configuration

| | |
|---|---|
| [settings.toml](settings.md) | The settings Trim itself reads, changed in place by its own pickers and window. |
| [Your own config](your-config.md) | `~/.config/trim/init.lua`, and why `~/.config/nvim` is not read. |

⌘, (Trim ▸ Settings…) opens a window over `settings.toml`. Every change is written into the file in place, comments
kept, and applied to the running editors at once.
