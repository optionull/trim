# The window

Trim's window is the editor with a few native panes around it. Each is optional and each is drawn by the app,
so it follows your colour scheme and font.

| | |
|---|---|
| [The file tree](tree.md) | Folders, git marks, diagnostics, a filter. |
| [Workspaces](workspaces.md) | Switch between repositories and worktrees. |
| [Tabs](tabs.md) | Open files, in the status bar, above, below or at the side. |
| [The status bar](status-bar.md) | Mode, file, diagnostics, language servers, position. |

A pane that takes the keyboard is a mode with a name in the status bar (TREE, SWITCH, RUN...), and Escape always
goes back to where you came from.
