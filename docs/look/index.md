# Look

The editor, the tree, the tabs, the status bar and the panes all follow one colour scheme and one font, and both are
chosen the same way: a list over the window where each choice is tried as the keyboard moves.

| | |
|---|---|
| [Colour schemes](themes.md) | tokyonight, catppuccin, rose-pine, and nvim's own. |
| [Fonts](fonts.md) | Any installed monospaced family, size and line height. |
